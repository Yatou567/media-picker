# 拾光 · Media Picker

一个无需账号、无需构建的 Chrome Manifest V3 插件，用于列出网页中的图片、视频和音频，并支持单项下载、批量下载、点选元素下载。

无第三方运行时依赖。当前为初始版本，已通过 16 项离线测试，真实 Chrome 安装与下载兼容性仍待验证。

## 安装（约 1 分钟）

优先使用仓库 **Releases** 中的插件 ZIP，解压后选择 `media-picker` 文件夹加载。也可以下载完整源码：

1. 点击仓库页面的 **Code → Download ZIP** 下载源码并解压，或使用 Git 克隆仓库。
2. 在 Chrome 地址栏输入 `chrome://extensions` 并回车。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择 **直接包含 manifest.json 的仓库根文件夹**（从 GitHub 下载后通常名为 `media-picker-main`）。
5. 点击 Chrome 右上角的拼图图标，把「拾光 · 网页资源下载」固定到工具栏。

这是可加载的源码项目，尚未上架 Chrome 商店。不要把 ZIP 当作 CRX 拖入安装。安装后请保留源码文件夹；移动文件夹后需重新加载。

## 使用

打开普通 http/https 网页，点击「拾光」图标，即会扫描并列出当前网页里发现的资源。弹窗打开期间，每两秒检查更新；弹窗关闭后不会自动下载。

- **分类与搜索**：按图片 / 视频 / 音频切换，可搜索文件名、链接或描述。
- **单项下载**：点击资源旁的「下载」，选择保存位置。
- **批量下载**：勾选资源，或「全选当前结果」，再点击「下载所选」。每次最多 100 项；已有勾选会跨分类保留。Chrome 自身的“下载前询问保存位置”设置可能使批量下载也弹出保存框。
- **点选元素**：点击「点选元素」，弹窗关闭后，将鼠标移到网页元素上并单击。选中元素及其内部发现的媒体会显示在浮层中，点击下载即可。可继续选择，按 Esc 或点击浮层右上角 × 退出。
- **复制链接**：可复制单项资源地址，适合需要交给其他工具处理的资源。
- **重新扫描**：图片未出现时，先向下滚动网页，让图片加载；音视频可先播放几秒，再打开插件或点击刷新。
- **查看进度**：弹窗内会跟踪本次会话提交的下载；最终状态以 Chrome 的 `chrome://downloads` 为准。关闭插件弹窗不会取消已提交的下载。

普通链接的文件名由 Chrome 根据网址和服务器响应决定；重名文件自动编号，不覆盖旧文件。

## 能发现哪些资源

图片元素、当前响应式图片和 srcset 候选、常见懒加载属性、CSS 背景与伪元素背景、内嵌 SVG、视频封面、video/audio/source 元素、带常见媒体扩展名的链接，以及页面性能记录中的可识别媒体 URL。支持可访问的同源 iframe 和开放的 Shadow DOM；按完整 URL 去重，保留签名参数。

## 已知边界

- `blob:` 临时资源、HLS/DASH 播放清单和 TS 分片会标注为不能直接下载完整文件。本版不抓取或合并流媒体，不解密 DRM。
- 部分站点只有分片或受保护的视频源，因此即便网页能播放，插件也不一定能下载。
- 需要特定鉴权、Referer、POST 请求、已过期签名或防盗链的资源，可能被服务器拒绝。插件不会绕过网站的访问限制。
- 跨域 iframe、封闭 Shadow DOM、尚未加载的内容、仅存在于脚本内部且无法识别的链接，可能不在列表中。可将跨域框架内容单独在新标签页打开后扫描。
- 内嵌 SVG 保存的是其标记，依赖网页外部 CSS 或字体的 SVG 不保证视觉完全一致。CSS 背景图保存的是原图，不是网页截图。
- 不支持 Chrome 内部页面、扩展商店、其他扩展页面、PDF 内置查看器和本地 `file://` 页面。
- 大型页面第一次扫描可能较慢。资源预览可能因网站防盗链而显示占位图；下载仍可尝试。

## 权限与隐私

仅申请 `activeTab`、`scripting`、`downloads`。点击插件后临时读取当前网页，不申请所有网站的长期访问权限。无账号、无统计、无上传服务，也不会持久化资源列表。预览和下载会向对应资源服务器发起正常请求；下载历史由 Chrome 管理。

## 验证记录

- JavaScript 语法检查通过。
- 16 项离线测试通过：分类、懒加载、响应式图片、去重、签名参数、资源限制、动态更新、重复注入、批量错误隔离、文件参数与 Manifest 权限等。
- 离线测试使用 DOM / Chrome API 模拟，不替代真实浏览器测试。尚未验证真实 Chrome 安装、页面布局、点选交互和网络下载。具体站点的兼容性需要安装后确认。

在仓库根目录执行：`node tests/run.cjs`。需要 Node.js，无需 npm install。

安装后建议在一个有图片的普通网页验证：打开插件 → 搜索和分类 → 下载一张图片 → 批量下载两项 → 点选一个图片元素 → 按 Esc 退出。再在含直链音视频的网页分别验证音频与视频下载。
